# 智护中轴 · 数启文脉

北京中轴线数字文化遗产交互展示系统。纯前端、可本地运行的课程社会实践展示原型。

用于《习近平新时代中国特色社会主义思想概论》课程“科技创新行”主题展示。围绕最终开题PPT中的数字保护、数字展示与青年创新，制作可自己操作并录屏的轻量原型。

## 直接使用

双击 `启动展示.cmd`，或用 Edge / Chrome 打开 `index.html`。无需安装依赖，无需联网，无需登录。

文件要放在同一个项目文件夹中，保留 `assets/` 目录。录屏前建议最大化浏览器，按 F11 全屏，使用系统现有录屏软件开始录制。页面自身不录制音视频。

## 展示内容

打开后进入六章展厅，可按底部“下一章”顺序讲解，也可点击顶部章节自由切换。

1. **序章**：约6.5秒的轴线点亮开场，7.8公里计数和15个节点逐步出现。可随时跳过、进入导览或重播。系统设置为减少动画时直接显示完成画面。
2. **读懂中轴**：15个遗产构成要素空间示意图。点击节点平移并推近镜头，已走过的轴段保持点亮；可查看两次实践计划路线和独立实践点位、切换历史时间轴、收藏知识卡或开启6站沿轴漫游。知识卡依次解释“是什么 / 为什么重要 / 现场看什么”。
3. **科技守护**：正阳门城楼三维样板，可拖动旋转、缩放、切换预设视角、自动环绕、展开与合拢部件；保留模拟环境情景及保护流程解释。
4. **科技讲活**：以正阳门为例，操作三页手机知识卡，体验从空间导览到移动阅读的内容组织；可保存包含原创插图和三段知识的完整 SVG 图片，也可跳到地图操作。
5. **青年尝试**：两次实践计划、FIND / BUILD / TEST 研究过程，以及“问卷设计 / 观察与访谈 / 体验任务”三个可切换面板。问卷总目标50—80份、第一次现场20—30份均标为计划，不显示虚构成果。
6. **尾声**：把保护、传播和青年实践联系到“深入实施创新驱动发展战略”和“坚持科技自立自强”，引用二十大报告相关摘句，以现场调研和改版计划收尾。

快捷键：`PageDown` / `PageUp` 切换章节；导览中使用 `←` / `→` 切换节点、空格启动或暂停自动导览；`F` 切换网页全屏，`R` 开启或退出录屏界面（隐藏页眉，将章节控制收为底部浮条）。输入框与弹窗内不触发这些快捷键。浏览器不支持网页全屏时使用 F11。

自动导览每站12秒，依次展示钟鼓楼、景山、故宫、正阳门、先农坛、永定门。镜头随每站移动，轴段依次点亮。在地图点击节点、切换路线或历史时间轴、手动操作镜头均可暂停漫游。页面转入后台也会暂停。

全景按钮恢复整条轴线，聚焦按钮在节点自动推近后进一步放大，到位后显示“已聚焦”。切换节点或返回全景后可再次使用。底部节点条可直接跳到画面之外的节点。实践一显示正阳门—前门周边及大栅栏拓展线；实践二显示古代建筑博物馆—永定门及景山拓展线。遗产保护中心的参访位置尚未确认，仅在路线说明中列出，不在地图虚构定位。

历史时间轴展示13世纪起源、16世纪外城修筑与轴线南延、2024入遗与2025立法三个节点。底图始终是今天的空间示意，早期轴段仅提示起源区位，不标注历史精确边界或复原建筑。

1920×1080下六章采用整屏排版；更小窗口自然滚动，不裁切内容。录屏界面只整理画面，不会启动录像。底部浮条仍可翻章和退出录屏界面。展示画面中的详细边界与来源统一收进“资料说明”。环境曲线仅保留一个“模拟演示”标记；研究页集中交代原型与调研的进度，样本量和地图路线标为计划。

## 管理模式与资料录入

展示章节不出现编辑、导入或反馈表单。按 `Shift+M`，或打开地址末尾的 `#admin`，进入管理模式，再按一次 `Shift+M` 或点击“返回展厅”退出。管理模式用于分开展示和编辑，没有账号登录或访问权限控制。

在管理模式的“实践记录与备份”中添加实际观察、已授权的访谈摘录、问卷说明或体验记录，可附一张不超过1MB的 JPG / PNG / WebP 照片。内容需匿名化，并确认课程使用授权。“体验反馈”页保留匿名反馈表与本机统计。不要把试填反馈计入真实研究样本。

资料保存在当前浏览器的本地存储中，最多60条实践记录、1000条反馈。大图可能提前耗尽浏览器容量，界面会提示导出。未能写入浏览器存储时，数据只在当前页面保留，关闭前务必导出。

通过“导出资料包”保存 JSON 备份。在另一台电脑或另一浏览器使用“导入资料包”，会合并不重复的记录、反馈和收藏，不覆盖原有材料。数据中包含照片时，备份文件也包含照片。

文件打开方式与 `http://127.0.0.1:4173`、`http://localhost:4173` 属于不同存储位置。请固定使用一种启动方式和同一个浏览器；更换方式前先导出。浏览器隐私模式、移动项目文件或清理网站数据也可能影响资料保留。

## 可选的本地预览

已有 Node.js 时，在项目目录执行：

```powershell
npm.cmd start
```

随后打开 `http://127.0.0.1:4173`。该命令只提供本机静态文件，不接收上传、不提供业务接口，也不对局域网开放。端口占用时可先设置 `$env:PORT='4174'`。关闭启动命令所在终端即可结束。

仅打开已生成的展示页面不需要 `npm install`。开发时可执行 `npm.cmd run check` 检查 JavaScript 语法。

## 正阳门三维样板

进入“科技守护”章节即可操作。模型依据公开参考制作，区分了正阳门城楼与箭楼，包含台基、下层柱廊、下层屋檐、上层柱廊、中层屋檐和上层屋顶六组部件。

- 鼠标拖动旋转，滚轮或双指缩放；也可点击“正面、侧面、俯看、斜向”及加减按钮。
- “结构展开”滑块分开部件，“复位”恢复材质、合拢部件并回到初始视角。
- “自动环绕”开始镜头环绕，再次点击暂停；直接拖动模型也会暂停环绕。
- “线框观察”显示真实网格结构，切回“建筑材质”恢复颜色与表面。

模型文件为 `assets/models/zhengyangmen.glb`，含六组部件和一段4秒的展开、合拢动画。网页的滑块独立控制部件位置。直接在其他三维软件中查看文件时，牌匾底板保留，文字由本网页运行时绘制。

运行库、模型和几何源码均随项目保存，不依赖 CDN。通过本地预览打开时加载 GLB；直接打开 `index.html` 时用相同源码即时生成模型，避开浏览器对本地模型请求的限制。浏览器不支持 WebGL 2 时保留平面示意。

模型源码在 `models/zhengyangmen.mjs`，交互在 `viewer3d.mjs`。修改后运行：

```powershell
npm.cmd ci
npm.cmd run build:3d
```

构建会生成 GLB、本地三维运行文件和模型说明，并核对模型可重新加载、部件与动画完整、门洞贯通。Three.js 使用 MIT 许可，原文随附于 `assets/vendor/THREE-LICENSE.txt`。建筑外观参考见 `docs/3D素材与建模依据.md`。

## 内容边界

项目内不包含虚构的真实调研结果。路线、问卷目标等来自开题材料，均作为计划展示。尚未获得的问卷、访谈和照片需自行补充。

地图、建筑和历史图层是原创讲解示意，不是地理导航、历史复原或精确测绘。数字保护页为模拟教学，不连接真实设备，不提供文物风险判断。知识卡中关于数字技术的描述是设计思路，不代表相应节点已部署该技术。

反馈统计只说明当前浏览器录入或导入了多少条反馈，不能代替独立参与人数、有效问卷数量或正式研究结论。

项目不预置调研照片、配音、视频或音乐。平面图形通过 SVG / CSS 绘制，三维建筑由网格几何生成，未把第三方参考照片用作贴图。展示时没有 CDN、地图密钥或网络字体依赖。
