# 内容与素材说明

## 采用的课程材料

以用户提供的《智护中轴_数启文脉_最终开题PPT.pptx》为主要依据：主题为“科技创新行”，核心知识点为“深入实施创新驱动发展战略”，围绕数字保护、数字展示、青年自主制作轻量导览与真实体验展开。

《北京中轴线习思想课程社会实践全流程实施方案.pdf》提供较早的实践执行背景。其理论重点及部分路线与最终开题PPT不同，页面未将这两套口径混为同一份最终方案。

用户提供的原始文件复制留存在本地 `参考材料/`。项目没有声称已经完成文件里安排的调研活动。

## 图形和数据

建筑图标、空间图谱和曲线通过 SVG / CSS 绘制。手机知识卡的彩色城楼插图由本项目原创 SVG 绘制，可导出为包含完整三段知识的 SVG 图片。正阳门城楼样板由三维网格生成，支持旋转与部件展开，独立模型文件在 `assets/models/zhengyangmen.glb`。所有图形用于解释空间关系和概念，不表达测绘精度、官方边界或具体文物内部结构。

历史时间轴使用起源短线、南延亮线及当代遗产节点光环解释空间演变，底图始终采用当前节点位置。早期短线仅为起源区位示意，不表示元代边界或历史实测长度，不提供建筑复原。实践点位不计入15个遗产构成要素；未确认位置的遗产保护中心仅列出参访计划。数字保护曲线是两组预设模拟数值，异常情景阈值不具有真实保护标准含义。

研究工具依最终开题PPT编排：问卷总目标50—80份、第一次现场20—30份，均为计划；理解程度、有效形式、使用障碍为问卷设计方向；观察清单是按PPT观察对象细化的拟用工具，不是观察结果。没有沿用较早PDF中的其他样本数量。

本项目不预置真实游客评价、问卷结果、访谈摘录或团队实地照片。页面不会将计划样本量转换成实际成果。

已收集正阳门城楼的公开照片和建筑说明作为3D建模参考，详见 `3D素材与建模依据.md`。参考文件保存在本地 `参考材料/3D建模参考/正阳门/`，照片未嵌入当前网页或模型，也不能作为团队实地调研材料。

## 展示文案

地图、建筑、历史与调研的详细说明集中在“资料说明”弹窗。普通展示中不重复强调精度、无设备、无预警或尚未调研；监测面板只保留一个“模拟演示”标记，研究页集中说明当前进度，并在路线与问卷数量处保留计划属性。资料录入与运行失败提示仍按实际情况显示。

## 使用前可以补充的材料

- 已获许可的实地照片，及能明确说明看到什么的观察记录。
- 已匿名化且已获授权的访谈摘录，注明时间、地点和对象类别。
- 实际问卷的样本来源、有效样本口径及统计说明。系统只提供文字记录，不会自动分析原始问卷表。
- 体验者实际完成任务的操作记录与意见。原型本机反馈不具有去重或身份核验功能。

缺少上述材料不会影响软件运行，但无法据此生成正式调研结论。录音、视频和配音仍需使用已有的拍摄、剪辑工具整理；本原型不提供媒体制作功能。

## 修改内容的位置

- `data.js`：节点文字、空间示意位置、两次实践计划、资料来源。
- `styles.css`：颜色、字号、布局及动效。
- `app.js`：交互、结构图形、模拟情景及本机资料处理。
- `models/zhengyangmen.mjs`：正阳门城楼三维网格与部件。
- `viewer3d.mjs`：三维材质、灯光、视角与动画交互。
- `tools/build3d.mjs`：模型导出、本地运行文件生成与模型完整性检查。
- `index.html`：标题、页眉和页脚。

编辑网页源文件后刷新浏览器即可看到变化。修改 JavaScript 后可执行 `npm.cmd run check` 做语法检查。
