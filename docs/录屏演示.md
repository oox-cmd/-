# 课堂录屏操作参考

按约2分40秒设计。可依自己的语速调整，画面切换应给听众留出阅读时间。此脚本适合展示软件原型，无法替代包含实地影像、访谈和调研发现的完整实践微纪录片。

## 开始前

1. 双击 `启动展示.cmd`，最大化浏览器，确认处于“全景导览”的“全景”图层。
2. 如需展示一手材料，提前在实践档案录入实际观察或已获授权的照片。没有材料时，保留空白状态即可。
3. 按 F11 或点击右上角全屏，调整系统分辨率和浏览器缩放，确保文字可读。可按 R 弱化页眉与页脚。录屏用电脑已有的软件完成。
4. 建议手动切换节点，避免自动导览与讲解节奏不一致。需要连续画面时再开启自动导览。

## 0:00—0:25 / 建立主题

画面：全景导览首页，停留片刻，点击故宫、正阳门。

讲解参考：

> 这是我们制作的“智护中轴·数启文脉”数字导览原型。北京中轴线纵贯老城南北，全长7.8公里，包含15个遗产构成要素。我们希望把实地观察到的知识理解问题，转化成可以操作的小工具，让公众更容易读懂遗产。

## 0:25—0:55 / 数字展示

画面：点击景山、先农坛，展示右侧知识卡。切换一次历史图层，再回到全景。

讲解参考：

> 在地图中点击节点，可以看到“是什么、现场看什么、数字技术能做什么”。例如在景山，我们关注整体空间和南北视线。在先农坛，我们关注传统建筑知识如何通过实物、模型和展陈被公众理解。历史图层用于强调不同时期的叙事重点，地图和建筑都是讲解示意。

## 0:55—1:35 / 数字保护

画面：进入数字保护。将结构展开滑块从0拖到100，点击线框观察。再切换异常情景，停留几秒，恢复常态。

讲解参考：

> 建筑结构演示把复杂的形态拆成可观察的层次。另一侧的预设曲线说明连续记录和变化提示的思路。这些都是教学模拟，没有连接真实设备。实际文物保护需要专业采集、资料建档、连续观察和人工研判，我们用交互说明这个过程。

## 1:35—2:05 / 真实实践材料

画面：进入实践档案，展示两次路线与实际录入的记录。

有材料时的讲解参考：

> 我们把两次实践计划和材料放在一起。每条观察关联具体节点，并保留材料来源与记录内容。这里展示的是我们实际获取并经过授权的材料，后续可以导出备份，用于课程分析。

无材料时的讲解参考：

> 这里保留了两次实践计划和真实材料的录入入口。当前尚未导入一手材料，所以页面不展示调研结论。后续可以将实际观察、访谈摘录和已授权照片关联到节点，再导出备份。

## 2:05—2:40 / 青年创新与课程联系

画面：进入青年共创，展示需求发现、原型设计、真实体验、反馈改进。可演示反馈表，但录屏试填产生的反馈不可当作真实研究样本。

讲解参考：

> 这个原型对应课程中深入实施创新驱动发展战略的知识点。我们的尝试从具体需要出发，用软件工程所学把知识重新组织，再邀请真实体验者完成任务并提出意见。原型是否有效，仍要看真实操作记录与反馈。通过这样的实践，我们理解科技创新怎样进入文化保护与传播的具体场景。

## 可选的体验任务

给体验者一句任务：“找到正阳门，说出一个现场观察重点，再打开数字保护页面，把建筑结构展开。”

记录其是否独立完成、在哪一步停顿、用了多长时间、提出什么具体问题。反馈表只记录理解感受，不能单凭均分证明原型有效。保留真实测试记录，比较修改前后的具体问题。
